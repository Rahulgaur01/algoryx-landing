# Algoryx Landing Page - Week 2 Task

A visually engaging, scroll-based animated landing page built with React, Tailwind CSS, and Framer Motion.

## 🚀 Features
- Responsive Navbar with smooth scrolling
- Animated Hero Section with Parallax effect
- Animated Counters (Stats section)
- Scroll Reveal Animations (Features & Pricing)
- Interactive Cards with hover effects
- Validated Contact Form
- Dark/Light Theme Toggle
- Scroll Progress Bar
- Fully Responsive Design

## 🛠️ Tech Stack
- **React (Vite)**
- **Tailwind CSS**
- **Framer Motion**
- **React Icons**
